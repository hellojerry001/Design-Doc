## 快速对照

| 你想做什么 | 去这里 |
|-----------|--------|
| 看某个接口的参数与返回值 | 按「单接口页模板」新建一页 |

> 单接口页的骨架固定为：
> `# 名称 → ## 功能描述 → ## 参数 → ## 返回值 → ## 调用示例 → ## 实现位置 → ## 注意事项 → ## 相关接口`。
> 骨架模板见 skill 的 `templates/api-page.md`。
