# 组件总览

本页是「组件」板块的入口（hub）：先让人知道**有什么**，再点进单页看**怎么用**。

- 想一眼看完所有组件的实时效果 → [组件预览](/design/gallery)（长页面 + 锚点导航）
- 想查某个组件的参数 → 从下表点进去

## 组件清单

| 组件 | 来源 | 说明 | 文档 |
|------|------|------|------|
| Button 按钮 | `.demo-assets/button.js` | 触发操作的基础控件，支持主要 / 次要 / 禁用 | [Button](/components/button) |
| Badge 徽章 | `.demo-assets/button.js` | 状态标记，用于在一行文字里补充状态语义 | [组件预览](/design/gallery#badge) |

> 每个组件页都包含**可交互的实时预览**（调用真实源码）。新增组件时，
> 先在这一页的清单里加一行，再按模板补一页。
