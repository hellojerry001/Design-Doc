## 这份文档是什么

这是 `project-docs-site` 脚手架自带的示例站点，用于演示四个板块的组织方式：

- **指南（Guide）**：讲清楚架构、目录与模块职责 —— 「怎么用、为什么」。
- **设计（Design）**：设计变量 / 图标资源 / 组件预览。三页都是长页面 + 锚点导航 —— 「长什么样、怎么复现」。
- **组件（Components）**：单个组件的 API 与实时预览 —— 「是什么、参数表」。
- **API**：接口与命令参考 —— 「怎么调用、返回什么」。
